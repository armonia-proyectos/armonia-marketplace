# Marketplace de ArmonIA (plugins de Claude Code)

Este repositorio es el **marketplace de plugins de Claude Code de ArmonIA**. Solo lista los módulos curados: su nombre,
su descripción, el repo donde vive cada plugin y el commit exacto (`sha`) que se revisó.

- **No se edita a mano.** Lo genera `publicar_catalogo.py` desde las fichas del catálogo de ArmonIA.
- **El acceso es el derecho.** Cada plugin vive en su propio repo privado; quien lo compró tiene lectura sobre él.
- **No avanza solo.** Cada plugin está fijado a su `sha` curado, sin `version`: una revisión nueva llega solo cuando se
  vuelve a curar y publicar.

Para activar un módulo en un proyecto, usa la extensión ArmonIA en VS Code («Módulos de ArmonIA»).
